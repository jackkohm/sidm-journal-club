# MARVELously Dark: journal club slides

Slides for a graduate journal club presentation on:

**Engelhardt, A., Munshi, F., Peter, A. H. G., Nadler, E. O., Cruz, A., Brooks, A. M., Zeng, Z. C., Quinn, T. R., & Keith, B.**
*MARVELously Dark: the density profile evolution of dwarf halos in velocity-dependent SIDM.*
[arXiv:2601.23264](https://arxiv.org/abs/2601.23264)

All figures from the paper are the authors' work, reproduced here with attribution for discussion.
Animations were made with [Manim](https://www.manim.community/) and [manim-slides](https://github.com/jeertmans/manim-slides).
The gravothermal "temperature map" and life-cycle animations use a schematic toy model, and the particle swarm
is a small N-body demonstration; neither is output from the paper.

View the slides: open `index.html`, or visit the GitHub Pages site for this repository.
Use the arrow keys or space to advance, F for fullscreen, Esc for an overview.
